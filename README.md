# 503IT-CYBER-RUN-GAME-EDUCATION-BY-AVENGERS
GROUP DETAILS - GROUP E & GROUP NUM 8
PROJECT TITLE - CYBER RUN
PROJECT AIM - THE AIM OF THIS PROJECT IS TO STUDY PHISHING ATTACKS TARGETING STUDENTS, ANALYZE THE TECHNIQUES USED BY CYBERCRIMINALS, EVALUATE STUDENTS AWARENESS OF PHISHING THREATS, AND PROPOSE EFFECTIVE PREVENTION AND CYBERSECURITY AWARENESS METHODS TO REDUCE PHISHING-RELATED RISKS IN EDUCATIONAL ENVIRONMENTS.
TARGET AUDIENCE - UNIVERSITY STUDENTS AGED 18–25 WHO USE EMAILS, ONLINE BANKING, AND SOCIAL MEDIA
CYBER SAFETY TOPIC - PHISHING AWARENESS
