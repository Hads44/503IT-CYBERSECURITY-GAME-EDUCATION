## Risk Management

| Risk                          | Possible Problem                               | How the Group Will Manage It                                         |
| ----------------------------- | ---------------------------------------------- | -------------------------------------------------------------------- |
| Tool is too difficult         | Prototype may not be completed on time         | Use Canva as a simpler backup tool for fast prototype creation       |
| Only one person does the work | Weak teamwork evidence and unfair task sharing | Assign clear tasks to every member and track GitHub commits          |
| AI overuse                    | Students may not fully understand the project  | Review, edit, and explain all AI-generated content before submission |
| Poor time management          | Final presentation may be rushed               | Set weekly deadlines and review GitHub progress regularly            |

This development plan shows how our group will move from the Cyber Run game idea to the first working prototype and final presentation while maintaining teamwork, clear responsibilities, and strong project management.
